# Docs

Sample guides and imported event models for this repository.

The eShop sample is `src/dotnet-es-eshop/`. The Facts Before Features book code is `src/facts-before-features/`.

| Path | Role |
|---|---|
| `models/` | Event model exports used by samples |
| `models/eshop/` | eShop event model JSON and plan (source of truth for that sample) |
| `models/facts-before-features/` | Harbor Street Books model for Facts Before Features (bookstore v1 and v2) |

These pages describe what the sample code does. They are not DocFX product documentation for LawnDart.

- `ESHOP_INFRA_PLAN.md`: hosting and bus design for the eShop sample
